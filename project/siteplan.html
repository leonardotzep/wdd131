Website Planning Document Guatemala Travel Guide

Site name

Guatemala Travel Guide - this name was chosen because it serves as a trave guide for visitors interested in exploring Guatemala. It provides tourist attractions, local culture, etc.
Possible domain: gttravelguide.com

Site Purpose

The site provides information about popular tourist attraction in Guatemala. Vistors can learn about different locations, local cultures, languages spoken in each area, etc.

Scenarios

  • What are the most populat tourist attraction to visit in Guatemala?
  • What are the 2 languagues most spoken in Guatemala
  • Where can I find photos and information about the most famous places in Guatemala?

Color Schema

#0D47A1 - Used for headings and navigation elements.

#2E7D32 - Used for buttons, links, and accents.

#F5F5F5 - Used as the page background color.

#3333 - Used for body text and paragraphs.

Typography

Poppins - Used for headings, navigation, and section titles.
